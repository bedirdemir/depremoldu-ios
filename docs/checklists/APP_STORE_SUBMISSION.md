# App Store Gönderim Kontrol Listesi

- [ ] `make verify` dondurulmuş `test` ağacında yeşil.
- [ ] `MARKETING_VERSION` ve `CURRENT_PROJECT_VERSION` güncellendi; `CHANGELOG.md` eşleşiyor.
- [ ] Fiziksel cihaz kabul listesi tamam veya tüm açık maddeler risk kaydıyla kabul edildi.
- [ ] Archive `DepremOldu-Release` ile alındı; upload sonrası build `Complete`.
- [ ] What to Test notu hazır.
- [ ] App Store açıklaması ve anahtar kelimeler Türkçe ve doğru.
- [ ] Ekran görüntüleri: liste, harita (faylar açık), Afet Bilinci, Hakkında.
- [ ] App Privacy: veri toplanmıyor; izleme yok.
- [ ] Yaş derecelendirmesi ve içerik anketi tamam.
- [ ] Destek/marketing URL'leri çalışıyor.
- [ ] Sorumluluk notu açıklamada ve uygulamada görünür.
- [ ] `test -> main` PR'ı merge edildi; `vX.Y.Z` tag oluşturuldu.
